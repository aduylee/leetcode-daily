## 📝 Example

### Two Sum

**Problem:**
Given an array of integers `nums` and an integer `target`, return the indices of the two numbers that add up to `target`.

**Approach:**

1. Create a Hash Map to store previously visited numbers.
2. Calculate the required complement.
3. Check whether the complement already exists.
4. Return the corresponding indices.

**Complexity:**

```text
Time Complexity: O(n)
Space Complexity: O(n)
```
